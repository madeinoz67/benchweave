  • DC power supply — class-dc_psu.html The Layered Precision operator surface: readings, staged control, plot, channel table.
  • Digital multimeter — class-dmm.html The observation-pure operator surface: reading tiles, range-margin alert, preset preview, trend, channel table.
  • Oscilloscope — class-oscilloscope.html The acquisition surface: waveform canvas with trigger and cursor idioms, acquisition line, run panel, partial-capture alert.
  • Function generator — class-function_generator.html The pure-source surface: per-channel function cards, load-convention alert, settings table, waveform preview, preset and staged-output idioms.
  • Electronic load — class-electronic_load.html The energy-admitting surface: sink-channel reading tiles, sinking-margin alert, staged-draw idiom, input trend with configured-maximum line, channel table.
