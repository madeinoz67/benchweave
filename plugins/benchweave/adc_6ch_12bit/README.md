# ADC 6-channel 12-bit device project (protocol v2)

The wire-family v2 reference implementation for the 6-channel 12-bit ADC
board (issue #393): the v2 wire spec, the host-side reference code, the
scripted device emulator, and the modelled rate table. The firmware
DESIGN (scan/DMA pacing, wait-TC TX, negotiation handlers, cycle budget)
lives in the design record; the implementation is the plugin
repository's (PRD fold-in stance).
No descriptor, no adapter — those live in the contributor's repository,
untouched.

Layout (the documented device-project root shape):

- `docs/wire-protocol.md` — the v2 wire spec (normative); v1 recorded as
  superseded-but-cited history.
- `docs/rate-model.md` — the modelled rate table, regenerated by
  `tests/test_rate_model.py` from the frame constants (a hand-edited
  cell fails).
- Firmware: not shipped in this tree — the v2 firmware DESIGN (scan/DMA
  pacing, DMA TX with wait-TC discipline, negotiation handlers, cycle
  budget) lives in the design record; the implementation is the plugin
  repository's to adopt (PRD fold-in stance).
- `src/adc_wire/` — the host-side reference package: dual-format codec,
  negotiation state machine, counter-gap detector. Pure Python over the
  OTDP §8.1 transaction surface; no SDK import, no port.
- `tests/` — the six A2 negotiation cells + RED control, codec/gap
  cells, the rate-model regeneration, and the scripted emulator
  (v2 / v1 / silent-revert / drop-list variants).
CI: the `adc-6ch-highrate` job in `.github/workflows/device-plugins.yml`
runs the project's tests offline from an isolated copy.
