# ADC 6-channel 12-bit board — rate model

Labels follow the design record's honesty rules: **MODELLED** = wire
arithmetic from the frame constants; **ESTIMATE** = static cycle budget
(§7 of the design record), no silicon. Every number in the tables below
is REGENERATED by `tests/test_rate_model.py` from the frame constants in
`src/adc_wire/codec.py` — a hand-edited table cell fails the test. The
rate formula:

```
SPS(n_active, avg, baud, fmt) =
    1e6 / (n_active * max(avg,1) * t_conv + frame_bytes(n_active, fmt) * 10 / baud)
frame_bytes(n, slim) = 11 + 2n   # 5 header + 4 counter + n*u16 + 2 CRC
```

`t_conv` values: `31.6` = the v1 firmware-measured polled path;
`1.0` = ESTIMATE for the DMA-scan path (no silicon has measured it).

## Target sensitivity (19,000 SPS)

19,000 SPS needs 52.6 us/sample; row 4's wire time is 43.3 us, leaving
9.3 us of serialised slack — modelled-achievable only on the DMA path
(row 4). Without the firmware DMA work the same protocol changes deliver
row 5's 13.3k. The 19k CLAIM is an estimate behind the design's human
bench gate (Part B); the no-hardware proof gates the wire+host half.
