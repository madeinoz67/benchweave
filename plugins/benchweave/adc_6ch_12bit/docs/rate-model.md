# ADC 6-channel 12-bit board — rate model

Labels follow the design record's honesty rules: **MODELLED** = wire
arithmetic from the frame constants; **ESTIMATE** = the remaining static
assumption (the pipelining operator — true in the firmware BECAUSE the
stream path waits the previous frame's transfer-complete before each
kick; see wire-protocol.md and main.c dma_tx_kick). Every number in the
tables below is REGENERATED by `tests/test_rate_model.py` from the frame
constants in `src/adc_wire/codec.py` and the conversion constants here —
a hand-edited table cell fails the test.

Conversion time per channel (COMPUTED, not measured — the vendor's own
numbers, `Peripheral/src/ch32v00X_adc.c`): sample time CyclesMode5 =
55.5 cycles + 12.5-cycle conversion = 68 ADC cycles; ADCCLK = PCLK2/8 =
48 MHz / 8 = 6 MHz; `t_conv = 68 / 6 MHz = 11.33 us` per channel. This
supersedes the design record's 1.0 us ESTIMATE (see the dated addendum
there).

Byte rate: baud / 10 (10 bit-times per 8N1 byte); at 3 Mbps that is
300 kB/s.

The rate formula, per row operator:

```
wire_us(frame) = frame_bytes * 10 / baud * 1e6
v1 (polled, serial sum):   total = n_active * T_MEASURED + wire
v2 (scan + DMA, pipelined): total = max(n_active * t_conv, wire)
frame_bytes(n, slim) = 11 + 2n   # 5 header + 4 counter + n*u16 + 2 CRC
```

`T_MEASURED` = 31.6 us/channel, firmware-measured on the contributor's
v1 polled path (config-write + EOC busy-wait + read + loop overhead on
top of the 11.33 us the ADC itself needs). The pipelined operator is
the remaining ESTIMATE; a serial-sum v2 row is kept beside it as the
conservative bound.

## Target sensitivity (19,000 SPS)

Row 4 is wire-bound at the 23,077 fps ceiling; 19,000 SPS uses 82% of
the wire, and the 52.6 us/sample budget leaves the CPU 9.3 us of slack
that the pipelined path spends building frames under the wire. Without
the firmware DMA work the same protocol changes deliver row 5's 13.3k.
The 19k CLAIM is a modelled figure behind the design's human bench gate
(Part B); the no-hardware proof gates the wire+host half.

Sensitivity note (fold M4): shorter sample-time modes exist — Mode0
(3.5 cycles) computes to (3.5 + 12.5) / 6 MHz = 2.67 us/channel, which
would clear 19k even on a serial-sum path. Sample-time choice is an
analog-quality decision (source impedance, settling) owned by the bench
checklist, not by this model; the table stays on CyclesMode5.
